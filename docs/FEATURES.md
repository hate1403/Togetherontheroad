# 동행 경험 확장 v0.4.0

8개 기능은 기존 실제 지도와 우측 그룹 패널의 ‘음악 · 인사 · 음성 · 여행 추억’에서 사용합니다. 참여자가 없으면 임의 참가자·노래·추억·주행 기록을 생성하지 않습니다.

| 기능 | 구현 범위 | 구분할 사항 |
|---|---|---|
| Sync Music | 실제 파일 전송, 서버 시각·예약 시작, 로컬 수신 동의, MediaPlayer 재생 위치 보정, MediaSession 재생/정지, 오디오 포커스 | MP3/M4A/WAV 최대 20MB. DRM·다른 구독 앱 제어 없음. 보정값은 추정 서버 시각에 대한 실제 플레이어 위치 차이이며 실차 간 동기 오차 보장 수치가 아님 |
| Car Wave | 인증된 15초 수명 인사 이벤트와 상대 지도 위 이모티콘, 3초 재전송 제한 | 화면 인사 구현. 앰비언트 라이트 제어는 연결하지 않음 |
| Ghost Car | 실제 수신 좌표의 차량 아바타·프로필, 아바타 5종, 직접 선택한 상태 | 임의 동행 차량이나 측정하지 않은 차량 상태를 생성하지 않음 |
| Walkie Talkie | 전경 화면의 마이크 권한·AAC 녹음, 최대 20초 녹음 후 전송, 수신함 선택 재생 | 연속 스트리밍 무전/통화가 아님. 화면 이탈 시 녹음 취소. 실제 마이크/스피커 검증은 기기별 필요 |
| Convoy Leader | 같은 목적지의 최신 도로 거리 순으로 선두/중간/후미 표시 | 실제 차간·차선 순서가 아님. 전체 거리 차이 100m 미만은 동행, 오래되거나 비교 불가능하면 대기 |
| Follow Me | 친구의 명시적 목적지 공유, 수신 차량이 승인해 자기 도로 경로 변경, Pleos 내장 내비 요청 | 공동 목적지 전체를 강제 변경하지 않음. 내장 내비 성공은 기존 실제 SDK 콜백 검증 사용 |
| Memory Drop | 지도 선택/현재 장소에 사진·음성 업로드, 100m 이내 서로 다른 관측 2회로 서버 잠금 해제, 기기 보관·삭제 | 위치는 단말 관측에 근거하며 위변조 방지 위치 증명은 아님. 서버 임시 보관과 개인 장기 보관 분리, 사진 자동 팝업/음성 자동 재생 없음 |
| Shared Journey Map | 동의 후 실제 관측 경로 수집, 여러 차량 경로 겹치기, GeoJSON 저장과 재열람 | 계획 경로를 주행 이력으로 저장하지 않음. 30초 이상 관측 공백·2km 이상 도약은 선으로 연결하지 않음 |

## 파일 선택과 공식 Pleos AVD

일반 Android는 Storage Access Framework의 시스템 파일 선택기를 사용합니다. 공식 Connect 2.1.0 AVD의 선택기는 `DocumentsUIStubWithResult`이므로 앱이 이를 감지하면 일회용 업로드 화면을 표시합니다.

1. 앱에서 음악 또는 사진 추억을 선택합니다. 추억은 지도에서 고른 위치 또는 최신 현재 위치를 확인합니다.
2. 화면의 서버 주소 `/upload`를 PC/휴대전화 브라우저에서 엽니다. 이 Mac의 AVD 검증은 `http://127.0.0.1:8787/upload`입니다.
3. 그룹 코드와 8자리 일회용 코드를 입력하고 실제 파일·공유 권한 확인을 선택합니다.
4. 음악은 선택한 실제 파일이 서버에 등록돼야 재생됩니다. 다른 참가자는 자기 차량에서 수신·재생에 동의합니다. 사진은 원본 EXIF를 전달하지 않도록 재인코딩합니다.

코드는 5분/1회/선택한 용도로 제한됩니다. 브라우저에는 그룹의 전체 권한 토큰을 주지 않으며, 업로드 전용 ticket도 URL에 넣지 않습니다. 그룹 탈퇴·만료 시 폐기됩니다. 기본 서버는 localhost에만 바인딩되므로 휴대전화 사용은 명시적으로 구성한 접근 가능한 동일 서버가 필요합니다. 운영은 HTTPS와 별도 인증·인프라 검증이 필요합니다.

## 보관과 삭제

- 주행 경로는 별도 동의를 받은 뒤의 관측만 저장합니다. 동의 철회 시 서버의 해당 차량 경로를 비웁니다. 다른 참가자가 GeoJSON으로 저장할 수 있다는 내용을 동의 문구에 표시합니다.
- 사진·음성은 그룹 서버의 메모리에 임시 보관합니다. 최대 64MB/그룹, 전체 128MB, 음악 20MB/파일, 기타 5MB/파일입니다. 그룹 만료는 기존 4시간이고 탈퇴 시 작성자의 미디어·추억·주행 기록을 제거합니다.
- 장소 잠금 전에는 snapshot에 파일 식별자를 내주지 않고 파일 다운로드도 서버에서 거절합니다. 잠금 해제는 30초 이내 유효 관측, 100m 이내 위치, 2초 이상 떨어진 두 관측을 요구합니다. 정확도가 제공되면 100m 이하를 요구합니다.
- ‘내 기기에 보관’으로 저장한 추억은 앱의 비공개 저장소에 남습니다. 다음 방문 시 가까운 추억 안내를 보며, 앨범에서 직접 삭제합니다. 자동 백업은 비활성화되어 있습니다.
- 서버 삭제는 이미 개인 기기에 보관하거나 외부 파일로 내보낸 사본까지 지우지는 않습니다. 별도 삭제가 필요합니다.

## 공식 근거

- [Pleos Vehicle SDK와 Light capability](https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/Vehicle/intro): 앰비언트 API의 존재와 실제 앱·차량 지원 확인은 구분합니다.
- [Pleos 음악 앱 가이드](https://document.pleos.ai/en/docs/pleos-only/vehicle-app-developer-guide/music-audio-app-developement-guide): 정식 미디어 앱 배포는 Media3/AAOS 및 미디어 라이브러리 등 추가 준수가 필요합니다. 현재 단일 공유 파일 기능을 정식 음악 앱 인증으로 표기하지 않습니다.
- [Android Audio Focus](https://developer.android.com/media/optimize/audio-focus): 포커스 손실 시 재생을 멈추며 안내·통화 등 우선권을 처리합니다.
- [Android MediaRecorder](https://developer.android.com/media/platform/mediarecorder): 실제 녹음은 전경 Activity에서만 수행하고 마이크 권한과 수명주기를 처리합니다.

Pleos의 외부 파일 저장기도 스텁이면 Shared Journey Map은 앱의 비공개 저장소에 실제 GeoJSON을 보관하고 지도에서 다시 표시합니다. 정상적인 Android 저장 선택기가 있는 환경에서는 선택한 외부 파일로도 내보냅니다. 보관한 지도는 내 기기의 추억 메뉴에서 삭제할 수 있습니다. 곡이 끝나면 종료 상태와 오디오 포커스를 정리하고 다시 재생할 수 있습니다.
