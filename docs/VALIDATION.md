## 에뮬레이터 장애와 검증 조건

하드웨어 GNSS의 `android.hardware.gnss.BpGnss.stopNmea`가 android.fg를 72~104초 막아 system_server watchdog이 재시작하는 로그를 확인했습니다. 앱 실행 전에도 발생했습니다. 이후 Android의 GPS test provider를 사용한 cold boot에서 동일 system_server PID 775가 35분 이상 유지됐고, 두 APK와 내장 내비의 실제 동작을 확인했습니다. 하드웨어 GNSS 문제가 해결됐다는 의미는 아닙니다.

별도 `scripts/avd-location.py`는 소유한 테스트 AVD에 개발자가 지정한 좌표만 공급하며 앱 실행과 분리됩니다. 화면에 AVD 테스트 위치라고 표시하고, 입력이 멈추면 30초 뒤 stale로 처리합니다. 실제 사용자 위치/차량 주행을 뜻하지 않습니다. 제품의 기본 참가자·좌표·ETA·성공 응답은 없습니다.

## 구현 범위와 남은 검증

공개 NaviHelper에서 OEM 지도 마커 삽입/카메라 투영 API는 확인되지 않았습니다. 현재 지도는 내비게이션 영역에 배치하는 앱 소유 MapLibre 지도입니다. 앱 OSRM과 내장 내비는 독립된 실제 경로 제공자이며 거리/시간이 같을 필요가 없습니다. 합류 경유지는 앱 지도 경로에 적용되며 OEM 내비에 자동 삽입하지 않습니다.

OSRM 예상 시간은 실시간 교통 ETA가 아닙니다. 실제 Vehicle State 기반 주행 상호작용 제한, 실차 위치/권한 승인, 운영 HTTPS 서버와 지도/경로 계약, release 서명, 다양한 화면 크기/접근성 검증은 남아 있습니다. 음성 기능은 제공하지 않습니다.

## v0.4.0 추가 기능 검증

확장 서버 테스트는 34개 중 33개 통과, 기존 외부 네트워크 1개는 기본 실행에서 skip했습니다. 일회용 업로드의 용도·만료·재사용 제한, 실제 WAV 길이와 신고 길이 불일치, 장소 잠금 파일 ACL, 관측 두 번의 해제, 동의 철회·탈퇴 삭제, 개별 Follow Me와 동일 거리 동행 판정을 포함합니다.

실제 로컬 서버와 공개 OSRM을 이용한 별도 통합 검증에서는 7,007m/3,818m 경로, 실제 WAV 업로드와 동일 바이트 다운로드, 음악 예약 시각/일시정지/재개, 음성 파일 전송, 실제 JPEG 장소 잠금/해제, 관측 이력 수집/철회, Follow Me 개별 도로 경로 3,189m가 확인됐습니다. 이 시험의 단말 위치와 미디어는 명시적인 개발용 입력입니다. 사람의 실제 음성·차량 주행 검증으로 취급하지 않습니다.

두 v0.4.0 APK의 빌드/Core 테스트와 Lint는 통과했고 Lint 오류·경고는 0개입니다. 공식 AVD에서는 차량 서비스 watchdog/ANR와 검은 화면이 재발했습니다. 기본 오디오 백엔드, 별도 테스트 GPS 제공자, 화면 유지 설정으로 재부팅 후 실제 지도와 새 기능 화면 검증을 재개했습니다. 환경 장애 원인을 앱 또는 메모리 부족으로 확정하지 않습니다. AVD 기본 호스트 마이크 입력은 허용하지 않았습니다.

공식 AVD의 실제 APK가 발급한 일회용 코드로 5,292,044바이트 WAV 파일을 전송해 HTTP 201을 받았습니다. Android media_session에서 앱의 TogetherSyncMusic 세션 active=true, PLAYING(3), 재생 위치 38,756ms, 실제 파일명 메타데이터를 확인했습니다. 이는 한 AVD의 실제 재생 확인이며 여러 차량 스피커 간 동기 오차나 사람의 음성 녹음 검증은 아닙니다.
